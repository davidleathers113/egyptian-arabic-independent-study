# AL4303 Analysis Workflow

Use this workflow for every phonological problem, whether the data are Egyptian Arabic or an unrelated language.

## 1. Preserve the data
Do not silently normalize transcription, spelling, token order, or morphological segmentation.

## 2. List observations before explanations
Record surface forms, environments, frequencies, and uncertainties without assigning phonemic status yet.

## 3. Identify phonetically similar segments
Ask which phones plausibly belong in the same analytical comparison set.

## 4. Search for contrast
Check identical environments first, then analogous environments. Distinguish true lexical contrast from transcription/elicitation noise.

## 5. Map distributions
For each relevant phone, list environments and determine whether distributions are complementary, overlapping, or insufficiently sampled.

## 6. Test variation
If two forms occur in the same environment, determine whether meaning, style, speaker, rate, morphology, or other variables correlate with the difference before calling it free variation.

## 7. Propose an analysis
State:
- proposed phoneme(s);
- allophone(s), if any;
- underlying representation when needed;
- process/rule;
- conditioning environment;
- feature/natural-class generalization;
- confidence level.

## 8. Seek disconfirming evidence
Design the next elicitation or find additional data that could make the hypothesis fail.

## 9. Compare alternatives
Prefer the analysis that explains the data with appropriate phonetic/typological plausibility and fewer unsupported assumptions, but preserve legitimate ambiguity.

## 10. External comparison only after freeze
After independently saving the analysis, compare it with a published grammar, instructor key, or AI system. Record changes rather than overwriting history.

## Egyptian Arabic hypothesis ledger

Maintain a table:

`ID | observation | current hypothesis | supporting evidence | conflicting evidence | next elicitation | confidence | status`

Recommended statuses: `open`, `testing`, `provisional`, `supported`, `rejected`, `unresolved`.

## Consultant-session principle

Do not ask the consultant to explain phonological theory. Use the consultant to provide forms, naturalness judgments, contrasts, repetitions, paradigms, and connected speech. The analytical responsibility remains with the student.
