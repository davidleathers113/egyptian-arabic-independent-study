# Project — AI Phonology Benchmark

## Research question

How reliably can current AI systems perform introductory field-phonological analysis when given the same finite datasets used by a human learner?

## Design

Use 6–10 datasets representing multiple analytical tasks:
- contrast/allophony;
- complementary distribution;
- natural classes;
- process conditioning;
- phonotactics;
- tone;
- morphophonemics.

At least half should be cross-linguistic datasets not derived from Egyptian Arabic.

## Order of operations

1. Complete the problem independently.
2. Freeze the human answer.
3. Grade/correct it using an authoritative key or instructor-quality source where available.
4. Give the same evidence to the AI with a standardized task prompt.
5. Preserve the AI output unchanged.
6. Score both against the evidence/key.

## Evaluation dimensions

- correct descriptive observations;
- correct contrast/distribution reasoning;
- correct underlying representation;
- valid conditioning environment;
- phonetic plausibility;
- unsupported assumptions;
- overlooked counterexamples;
- hallucinated data;
- confidence calibration;
- quality of stated uncertainty.

## Egyptian Arabic extension

For selected original data with no external answer key, compare:
- student analysis;
- AI analysis;
- published descriptions where applicable;
- additional consultant evidence elicited specifically to discriminate analyses.

Do not treat native-speaker judgments as direct answers to abstract phonological questions; use them as linguistic evidence.

## Final report

3,000–5,000 words plus scoring tables. End with concrete implications for AI-assisted language documentation and Bible-translation tooling: which tasks look suitable for suggestion/triage, which require trained human review, and what evidence an AI tool would need to expose for its recommendation to be auditable.
