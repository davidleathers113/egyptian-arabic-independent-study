# AL4303 Cross-Linguistic Problem-Set Bank

## Purpose

DIU's public AL4303 description emphasizes **numerous practical exercises**. This independent study therefore treats problem solving as the center of the course rather than an appendix to reading.

The bank has four levels:

- **Level A — review:** transparent, guided, self-checkable problems.
- **Level B — core:** field-analysis problems requiring an argued solution.
- **Level C — stretch:** theory-heavier or more open-ended university problems.
- **Level D — assessment:** unseen problems reserved for closed-AI midterm/final use.

Do not expose Level D solution material before the assessment.

MIT 24.961 is graduate-level and theory-heavier than the DIU prerequisite. **Inspect each PDF before assigning it.** Record:

- language(s);
- phenomenon;
- theory assumed;
- core skill practiced;
- estimated time;
- whether it is suitable now or should be deferred to future graduate study.

Do not assign every MIT problem. Select 3–5 that meaningfully extend the core syllabus.

# 4. Tone problem bank

The tone practicum must use genuine tonal data.

Preferred sources, in order:

1. legitimately accessible exercises accompanying Keith Snider's _Tone Analysis for Field Linguists_;
2. instructor-created practice derived from published, citable datasets without copying protected solutions;
3. MIT OCW tone lecture examples plus an independently sourced dataset;
4. another reputable university/textbook dataset with provenance and a solution/review mechanism.

Required practicum abilities:
- distinguish pitch observation from tonal analysis;
- keep grammatical/segmental contexts controlled where possible;
- identify contrastive patterns;
- distinguish level/contour behavior where relevant;
- represent tone without treating f0 traces as the phonological analysis;
- state uncertainty.

Egyptian Arabic pitch/intonation work cannot substitute for this practicum.

# 5. Egyptian Arabic data problems

Create original exercises from the private corpus **without publishing private audio/data unless permitted**.

Every Egyptian Arabic analysis packet should contain:

- de-identified token IDs;
- phonetic transcriptions/measurements needed for the question;
- lexical glosses where safe;
- morphological context where relevant;
- enough data to test at least two hypotheses;
- explicit counterexamples or apparent exceptions where available.

### Analysis sheet

For each problem answer:

1. What is directly observed?
2. What distribution is present?
3. Is there contrast?
4. What natural class is involved?
5. What process, if any, is proposed?
6. What environment conditions it?
7. What evidence supports the underlying representation?
8. What counterevidence exists?
9. What new elicitation would discriminate between analyses?
10. What is the confidence level?

Published descriptions are consulted only after this sheet is frozen.

# 6. Breadth quotas

Across graded problem sets, require:

- at least 50% non-Arabic formal datasets;
- at least one language with a substantially different phonotactic profile from Arabic/English;
- at least one true tone-language analysis;
- at least one vowel harmony or long-distance process problem;
- at least one nonconcatenative/morphophonemic problem;
- at least one stress/weight/prosodic problem;
- multiple language families where sources permit.

The goal is transfer, not collecting exotic language names.

---

# 7. Correction protocol

For every substantial problem:

### Pass 1 — closed analysis
No AI, solution key, published analysis, or web searching for the dataset.

### Pass 2 — confidence annotation
Mark each major claim:
- high confidence;
- medium confidence;
- low confidence.

### Pass 3 — check
Use legitimate solution/instructor material, reference analysis, or external feedback.

### Pass 4 — error analysis
For every material mistake classify the cause:
- missed datum;
- bad transcription assumption;
- confused phonetic/phonological level;
- distribution error;
- natural-class/feature error;
- rule/conditioning error;
- underlying-form error;
- overgeneralization;
- theory/notation confusion.

### Pass 5 — corrected solution
Write a corrected analysis in your own words.

The error log is part of the final portfolio because improvement matters more than pretending the first answer was correct.

---

# 8. Assessment reserve

Before the course begins, identify and quarantine enough unseen datasets for:

- midterm: 2–3 datasets covering contrast/distribution/features/processes;
- tone practical: 1 tonal dataset;
- final: 2–3 mixed datasets including morphophonemics/prosody.

Store assessment keys privately or in a protected location. Do not commit future answer keys to the public repository.
