# AL4410 Independent Study — Grammatical Analysis

**Status:** planned.

Modeled scope follows DIU's public description: techniques for analyzing/describing morphology and syntax across natural languages, including word classes, allomorphy, inflection, derivation, phrases, clauses, and sentences.

Egyptian Arabic will provide sustained application, including root-and-pattern morphology where appropriate, but exercises must include diverse language types so Arabic does not become the assumed template for grammar.

Planned workload: 180 hours.
