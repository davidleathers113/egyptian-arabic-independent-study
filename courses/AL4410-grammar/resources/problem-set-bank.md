# AL4410 Cross-Linguistic Problem-Set Bank

## Purpose

DIU describes AL4410 as involving **numerous practical exercises from a large variety of languages**. The course therefore treats analysis problems as the center of learning rather than as illustrations after reading.

Use four levels:

- **Level A — review:** guided/self-checkable introductory problems.
- **Level B — core:** Bickford/Payne-style data analysis requiring a defended solution.
- **Level C — stretch:** more open-ended university/typological problems.
- **Level D — assessment:** unseen problems quarantined for closed-AI exams.

---

# 1. Primary core source — Bickford

Use exercises/examples associated with the relevant chapters where available.

Core skill groupings:

### Morphemes and hypotheses
- segmentation;
- recurring form/meaning correspondences;
- competing segmentations;
- evidence vs. assumptions.

### Word classes
- distributional diagnostics;
- morphological diagnostics;
- category ambiguity;
- language-specific classes.

### Inflection/derivation/allomorphy
- paradigm induction;
- feature bundles;
- inflection vs. derivation;
- suppletion;
- morphophonemics;
- nonlinear affixation.

### Syntax
- constituency;
- syntactic categories;
- grammatical relations;
- phrase structure;
- valence/subcategorization;
- obliques;
- case/agreement;
- variable order;
- questions/commands;
- voice;
- embedded/relative clauses.

# 2. Major additional problem source — Thomas Payne

Official additional exercises:
https://pages.uoregon.edu/tpayne/problem_sets.htm

Payne's textbook itself contains almost 100 practical exercises, and the official exercise page adds chapter-organized problems.

Assign by topic:

- Ch. 2 exercises → morphology/processes/conceptual categories;
- Ch. 3 → morphophonemics;
- Chs. 4–5 → word classes/subclasses;
- Ch. 6 → constituent structure;
- Ch. 7 → typology;
- Ch. 8 → grammatical relations;
- Ch. 9 → voice/valence;
- Ch. 10 → multi-clause structure.

These should make up a substantial portion of Level B work.

# 4. MIT OCW practice

## MIT 24.900 Introduction to Linguistics (2022)

Use selected morphology and syntax lecture/problem material as Level A/B supplementation.

Especially useful: Problem Set 3 has students collect syntactic data from a native speaker of a language they are studying and present examples in interlinear form. Adapt the **method**, not the assignment wording, to Egyptian Arabic.

Potential use:
- early morphology practice;
- syntax Weeks 9–12;
- consultant-data collection model.

## MIT 24.902 Syntax

Eight public problem sets are available, but this course is theory-heavier than AL4410.

Before assigning any 24.902 problem:
1. inspect it;
2. identify formal assumptions;
3. state the descriptive skill it exercises;
4. use it only if that skill fits AL4410;
5. defer movement/binding/theory-heavy material when it belongs more naturally in later syntax study.

# 5. Typological challenge bank — WALS and Grambank

Do not simply ask “what type is language X?” Instead use typological databases to generate follow-up challenges after a primary analysis.

Examples:

### Marking systems
After analyzing case/agreement data, compare with WALS:
- locus of marking in the clause;
- number/position of cases;
- synthesis of the verb.

### Constituent order
After independently analyzing a language, compare:
- S/O/V order;
- adposition/NP order;
- adjective/noun;
- genitive/noun;
- numeral/noun;
- relative clause/noun.

### Grambank
Use feature pages to find languages with structures unlike Arabic/English, then obtain the original grammar or a legitimate instructional dataset before assigning analysis.

A database code is not an adequate problem-set solution.

# 6. Required structural breadth

By the end of graded work, the portfolio should demonstrate competence with datasets exhibiting as many of the following as practical:

## Morphological profile
- isolating/analytic structure;
- agglutinative morphology;
- fusional morphology;
- polysynthetic/high-synthesis data;
- concatenative affixation;
- reduplication/infixation;
- nonconcatenative morphology;
- suppletion/allomorphy;
- clitics/wordhood ambiguity.

## Grammatical relations/marking
- nominative-accusative-like system;
- an ergative-absolutive or otherwise non-English alignment pattern;
- head marking;
- dependent marking;
- rich agreement/indexing;
- case-rich data;
- minimal overt marking.

## Syntax
- head-initial and head-final patterns;
- flexible/order-variable language;
- NP structures unlike English/Arabic;
- multiple question strategies;
- voice/valence alternation;
- relative clauses with a strategy unlike ordinary English gaps;
- different complement/subordination strategies.

The point is **transfer of method**, not maximizing the number of language names.

# 7. Egyptian Arabic original-data problem format

Build original exercises from the private corpus without exposing private audio/PII.

Every packet should include only the data needed to reason about the question, with de-identified IDs.

### Morphology analysis sheet
1. What forms recur?
2. What meanings/functions recur?
3. What segmentation is proposed?
4. What alternatives are possible?
5. What paradigm is implied?
6. Which forms are predictable vs. irregular?
7. Is the process inflectional, derivational, lexical, or unresolved?
8. What morphophonemic evidence from AL4303 matters?
9. What additional forms would distinguish hypotheses?
10. Confidence level?

### Syntax analysis sheet
1. What is the construction/function being tested?
2. What constituents are supported by evidence?
3. What are the lexical/syntactic categories?
4. What arguments/obliques occur?
5. What grammatical-relation diagnostics apply?
6. What order is observed and how stable is it?
7. What morphology co-varies with the construction?
8. What negative/ungrammatical or contrastive judgments are available?
9. What competing description is plausible?
10. What elicitation would distinguish analyses?

Freeze before consulting reference grammar/AI.

# 8. Correction protocol

For every substantial dataset:

### Pass 1 — closed human analysis
No AI, morphological analyzer, reference grammar, WALS/Grambank lookup, web search for the exact dataset, or answer key.

### Pass 2 — confidence marking
Label major claims high/medium/low confidence.

### Pass 3 — check
Use legitimate solution material, instructor/reference analysis, published grammar, or expert feedback.

### Pass 4 — error classification
Classify material errors:
- segmentation;
- missed morpheme;
- gloss/feature mistake;
- allomorphy/conditioning;
- inflection vs. derivation;
- category/word-class diagnosis;
- constituent structure;
- grammatical relation/semantic role confusion;
- valence/argument structure;
- word order overgeneralization;
- clause-type/embedding analysis;
- imported English/Arabic assumption;
- notation/glossing error;
- insufficient evidence.

### Pass 5 — corrected analysis
Rewrite the analysis in your own words and preserve the original attempt.

---

# 9. Assessment reserve

Before the study begins, quarantine enough unseen material for:

- morphology midterm: 3–4 datasets spanning segmentation, allomorphy, inflection/derivation, and unfamiliar morphological type;
- syntax midterm: 2–3 datasets spanning constituency, grammatical relations, order, or clause structure;
- final: 3 mixed datasets requiring both morphology and syntax;
- one short interlinear-glossing correction task.

Do not commit future answer keys to the public repo.

---

# 10. Mastery principle

A good solution does not merely label structures. It shows:

`data → diagnostics → generalization → counterevidence → uncertainty → additional evidence needed`

A grammatically plausible story without that evidential chain does not count as a strong analysis.
