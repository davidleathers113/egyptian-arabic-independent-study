# Final Project — Preliminary Field-Phonetic Description

## Working title

**A Preliminary Field-Phonetic Description of Egyptian Arabic Speech from SPK001**

Aim for approximately 20–30 polished pages excluding appendices, but quality/evidence takes priority over page count.

## Required sections

1. **Purpose and scope** — what the project does and does not claim.
2. **Speaker profile** — minimal public-safe relevant background.
3. **Method** — recording environment, equipment, elicitation, corpus size, annotation, measurement.
4. **Consonantal observations** — phones observed and articulatory descriptions.
5. **Vowel observations** — qualities, durations, contexts.
6. **Secondary articulations/posterior phenomena** — only where evidence supports discussion.
7. **Suprasegmental observations** — stress, duration, pitch/intonation at an introductory level.
8. **Acoustic investigation** — selected Praat measurements and figures.
9. **Connected-speech sample** — Arabic orthography if appropriate, broad IPA, selected narrow details, English gloss/translation as appropriate.
10. **Uncertainty and limitations** — speaker/sample limits, elicitation effects, analytical uncertainty.
11. **Next questions** — items handed to AL4303.

## Minimum data target

A useful planning target:
- 75–100 lexical items;
- 20–30 phrases/sentences;
- 3–5 minutes of connected speech;
- enough repeated controlled tokens for at least one acoustic mini-analysis.

The project may use more or less data when methodologically justified.
