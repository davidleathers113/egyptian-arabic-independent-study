# Midterm Practical Specification

Target placement: end of Week 6.

## Conditions

- no generative AI;
- closed notes except any explicitly permitted IPA chart portion;
- record oral/production sections;
- preserve the first attempt.

## Components

1. **IPA recognition** — identify/describe symbols.
2. **IPA production** — produce prompted phones.
3. **Articulatory description** — describe unfamiliar prompts by place/manner/phonation/airstream as applicable.
4. **Vocal-tract diagram** — label from memory.
5. **Auditory transcription** — broad transcription of unfamiliar speech samples.
6. **Egyptian Arabic sample** — transcribe a short previously unstudied consultant clip.
7. **Short explanation** — distinguish phonetic observation from a phonological claim.

## Scoring

Use an explicit rubric created before the test. Record error categories, not merely a percentage, so Weeks 7–12 can remediate specific deficits.
