# Week 0 — Baseline

## Goal
Capture what you can genuinely do before retraining.

## Tasks
- Read only the repository policies/instructions necessary to administer the baseline.
- Complete `assessments/baseline-assessment.md`.
- Record a short baseline consultant session with consent.
- Save private master audio and public-safe metadata.
- Log all time.
- Enter competency status as `not started` or `developing` without embarrassment.

## Do not
- study IPA charts first;
- ask AI for transcriptions;
- search Egyptian Arabic phonetic inventories before attempting the baseline;
- overwrite mistakes.

## Output
A frozen `baseline_v0` package plus a one-page prediction/reflection.
