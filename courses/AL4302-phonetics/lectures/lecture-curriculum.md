# AL4302 Lecture / Tutorial Curriculum

Lectures support practice; they do not substitute for it.

## Core public sources

1. **MIT OpenCourseWare — Linguistic Phonetics**  
   https://ocw.mit.edu/courses/24-915-linguistic-phonetics-fall-2015/
2. **International Phonetic Association resources**  
   https://www.internationalphoneticassociation.org/
3. **UCLA Phonetics Lab Archive**  
   https://archive.phonetics.ucla.edu/
4. **Praat official Intro/manual**  
   https://www.fon.hum.uva.nl/praat/manual/Intro.html

## Lecture log

For every counted lecture/tutorial record:
- source/institution;
- title/topic;
- duration;
- date;
- 5–10 key notes;
- questions;
- associated learning outcomes;
- practice performed immediately afterward.

## Selection rule

Prefer university/association/official-tool material. YouTube explanations can supplement weak spots, but record the creator's credentials/source and verify technical claims before treating them as authoritative.
