# AI and Language Technology Research

This directory holds the longitudinal research thread connecting formal linguistic preparation with responsible AI-assisted Bible-translation work.

## Principle

Do not begin with the assumption that AI should replace a linguistic task. Begin with a task, define the human evidence standard, evaluate AI against that standard, and document failure modes.

## Reusable experiment sequence

1. Define a narrow linguistic task.
2. Produce/freeze the human analysis first.
3. Define the input available to the model.
4. Run the model reproducibly.
5. Score outputs against evidence, not confidence/style.
6. Ask where native-speaker/community judgment is indispensable.
7. Record safe assistive uses and unsafe delegation uses.
8. Preserve model/version/date because capabilities change rapidly.

## Research arc

Phonetics → phonology → morphology/syntax → language acquisition → translation/semantic consistency → human/community governance.
