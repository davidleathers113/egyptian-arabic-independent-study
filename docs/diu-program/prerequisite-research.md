# DIU Prerequisite Research

## Current public course descriptions

DIU's distance/nontraditional course page currently lists the four courses this independent-study program is modeling:

| Course | Credits | Publicly described focus |
|---|---:|---|
| AL4302 | 3 UG | IPA recognition/production/transcription, suprasegmentals, speech production, basic acoustic analysis |
| AL4303 | 3 UG | phonetic vs. phonological data, features/classes, distribution, contrast, processes, tone, morphophonemics |
| AL4410 | 4 UG | morphological and syntactic analysis across natural languages |
| AA4305 | 3 UG | learner-directed language/culture acquisition plus native-speaker lab |

Source: https://www.diu.edu/online-courses/ (checked 2026-08-09).

## Important status note

This repository uses these descriptions for **curricular alignment**, not institutional equivalency. DIU controls admission, prerequisite waivers, transfer/equivalency, grading, and program requirements. Course offerings can also change by term.

## Why intentionally complete all four areas

Even if prior undergraduate work might support a waiver, the independent-study strategy intentionally treats the sequence as a fresh academic foundation. The purpose is to:
- refresh knowledge after a long gap;
- generate recent evidence of academic readiness;
- relearn analytical habits before graduate work;
- create a coherent progression from speech data to phonological, grammatical, and acquisition analysis.

## Research maintenance

Before beginning each new independent study:
1. re-check the official DIU course description;
2. capture the date checked;
3. revise the alignment matrix if the public description changes;
4. never present this project as DIU-sponsored or DIU-approved.
