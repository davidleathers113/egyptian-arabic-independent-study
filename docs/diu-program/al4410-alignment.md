# DIU Alignment — AL4410 Principles of Grammatical Analysis

Source boundary: DIU's public AL4410 description current when this document was built. Re-check DIU before relying on it for admissions/current scheduling.

| DIU-published focus | Independent-study evidence |
|---|---|
| techniques for analyzing/describing morphology and syntax | 16-week analysis sequence + final grammar sketch |
| numerous practical exercises | minimum 14 substantial graded cross-linguistic datasets |
| large variety of languages | at least half of formal graded datasets must be non-Arabic |
| determine word classes | Week 2 diagnostics and exams |
| allomorphy | Week 3 problem sets/paradigms |
| inflectional morphology | Week 4 analyses + morphology midterm |
| derivational morphology | Week 5 analyses + case work |
| phrases | Weeks 9–11 constituent/phrase analyses |
| clauses and sentences | Weeks 12–14 clause/complex-sentence work |

## Deliberate extensions

- nonlinear/root-and-pattern morphology project;
- word/clitic boundary analysis;
- interlinear-example discipline;
- longitudinal Egyptian Arabic grammatical sketch;
- AI grammar-induction benchmark;
- oral defense.

Extensions are included because they strengthen field preparation; they should not replace cross-linguistic core analysis.
