# DIU Alignment — AA4305 Second Language and Culture Acquisition

Source boundary: DIU's public AA4305 description current when this document was built. Re-check DIU before relying on it for admissions/current scheduling.

| DIU-published focus | Independent-study evidence |
|---|---|
| learner-directed second-language acquisition | personal needs analysis, acquisition plan, strategy experiments |
| learner-directed culture acquisition | culture hypothesis/participation journal and final synthesis |
| emphasis on beginning stages | supported-comprehension and participation progression, adaptable to actual baseline |
| perspectives on language/culture learning | targeted SLA/culture readings and responses |
| strategies for cultural differences | culture-learning portfolio and revised hypotheses |
| practical native-speaker lab | minimum 24 hours documented acquisition-lab interaction |
| small-group/non-instructed setting spirit | explicit nurturer/acquisition-lab mode distinct from normal tutoring |

## Deliberate extensions

- repeated baseline/final communication evidence;
- ACTFL proficiency concepts used descriptively, never as an unofficial official rating;
- integration of prior phonetic/phonological/grammatical training as diagnostic support;
- AI language-coach benchmark;
- sustainable 6–12 month continuation plan.

The course is intentionally evaluated on learner-directed process and demonstrated communicative/cultural growth, not on memorizing SLA terminology.
