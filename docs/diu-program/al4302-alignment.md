# AL4302 Alignment Matrix

Official public description checked: 2026-08-09  
Source: https://www.diu.edu/online-courses/

DIU describes AL4302 as a 3-credit undergraduate course in which students use IPA to identify, pronounce, and transcribe sounds and suprasegmentals in natural speech, describe mechanisms of speech production, and receive an introduction to basic acoustic analysis.

## Competency-to-evidence map

| Target competency | Independent-study evidence |
|---|---|
| Identify speech sounds | weekly ear-training logs; baseline/midterm/final practicals |
| Pronounce speech sounds | recorded production drills; practical examination |
| Transcribe with IPA | weekly cross-linguistic and Egyptian Arabic transcription labs |
| Handle suprasegmentals | Week 8 stress/pitch/length/intonation labs |
| Explain speech production | articulatory diagrams; Essay 1; teach-back video; oral defense |
| Perform basic acoustic analysis | Praat labs; vowel study; consonant study; final practical |

## Deliberate extensions beyond the public description

These strengthen the study but should not be confused with stated DIU requirements:
- Egyptian Arabic field-consultant sessions;
- reproducible corpus metadata;
- AI evaluation experiments;
- public instructional artifacts;
- longitudinal baseline-vs-final comparison.

## Scope guardrail

If a task is interesting but does not strengthen one of the target competencies or a clearly labeled extension, it should not displace core phonetics practice within the 135-hour budget.
