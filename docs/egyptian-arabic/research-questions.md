# Egyptian Arabic Research Questions

This file stores questions, not premature conclusions. Questions can migrate into formal projects when enough data exist.

## AL4302 phonetics

- Which consonantal distinctions are hardest for an English-speaking learner to perceive and reproduce?
- How does SPK001 realize commonly described pharyngeal/posterior consonants in careful versus connected speech?
- What acoustic correlates accompany emphatic consonants in the consultant's speech?
- What is the observed vowel space for selected controlled tokens?
- How do duration and quality interact in the observed vowel system?
- What changes between isolated-word and connected-speech productions?
- Which suprasegmental cues are perceptually salient to the learner?
