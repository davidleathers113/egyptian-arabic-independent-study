# Egyptian Arabic Variety Notes

## Working principle

The field language should not be treated as a single abstract object called "Egyptian Arabic." The primary data come from one real speaker with a particular regional, social, educational, and linguistic history.

## Public-safe speaker description

Use a pseudonymous ID such as `SPK001`. Record privately, with consent, relevant variables such as:
- place raised;
- places lived long-term;
- first/home languages;
- other Arabic varieties used regularly;
- education/literacy background relevant to elicitation;
- exposure to Modern Standard Arabic;
- age range if analytically useful.

Only publish the minimum necessary description.

## Analytical distinction

Maintain separate labels for:
- consultant's spontaneous Egyptian Arabic speech;
- careful elicited Egyptian Arabic;
- Modern Standard Arabic reading/production when deliberately requested;
- metalinguistic judgments;
- student's own productions.

Do not infer spoken pronunciation directly from Arabic orthography.

## Field-note wording

Prefer:

> "In tokens collected from SPK001 under these conditions..."

rather than:

> "Egyptian Arabic always..."

The first wording keeps conclusions proportional to the evidence.
